# Regra de Design System & Identidade Visual (Andrade Serviços de Tecnologia)

Ao projetar, gerar ou modificar qualquer componente, página ou estilo neste repositório, você DEVE seguir estritamente as especificações abaixo:

1. **Estética:** Sóbria, sofisticada, matte dark minimalism (padrão Apple, Leica, Linear Dark Mode).
2. **PROIBIÇÃO ABSOLUTA:**
   - ZERO cor VERDE no site (sem botões, ícones, badges ou textos verdes).
   - ZERO cor ROXA/ÍNDIGO no site.
   - ZERO neon, sombras brilhantes (`box-shadow: 0 0 25px...`), ou orbs difusos no fundo.
   - ZERO gradientes em textos (`linear-gradient` em tipografia é proibido).
   - ZERO arco-íris ou efeitos exagerados de IA genérica.
3. **Cores Oficiais Homologadas:**
   - **Fundo Base:** `#090A0F`
   - **Superfície de Cartão:** `#0F1219` / `#131722`
   - **Títulos (H1, H2, H3):** `#FFFFFF` sólido (contraste 18.4:1 - WCAG AAA)
   - **Textos de Corpo:** `#CBD5E1` (contraste 12.8:1 - WCAG AAA)
   - **Textos Secundários / Muted:** `#94A3B8` (contraste 7.6:1 - WCAG AAA)
   - **Destaque Técnico / Brand / WhatsApp / Segurança / LGPD:** `#38BDF8` (sólido) ou `#FFFFFF`
   - **Bordas:** `rgba(255, 255, 255, 0.08)` ou `#1E2330`
4. **Tipografia:**
   - Primária: `'Plus Jakarta Sans', sans-serif`
   - Monospaçada / Métricas: `'JetBrains Mono', monospace`
5. **Botões:**
   - Primário: Fundo `#FFFFFF` sólido + texto `#090A0F` sólido.
   - Secundário: Fundo `#181D2B` + texto `#F4F4F5` + borda `rgba(255, 255, 255, 0.08)`.
6. **Escopo:** A Andrade Tech desenvolve software com IA, GEO & SEO, Time-to-Market acelerado, segurança OWASP e conformidade LGPD. A empresa **NÃO** trabalha com infraestrutura física ou cloud pura.
7. **Internacionalização:** 100% de suporte trilíngue (Português, Inglês e Espanhol).
